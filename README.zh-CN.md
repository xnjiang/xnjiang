# 你好，我是 xnjiang

[English](README.md) · [简体中文](README.zh-CN.md)

我在 [Qumge](https://qumge.com) 做 AI 产品，涵盖营销、学习、语音想法记录，以及拥有持续人格的 Agent。目前主要投入这五个项目。

## AutoWhisper — 为产品配一个 AI CMO

[AutoWhisper](https://autowhisper.xyz) 把产品研究、内容创作、审核和定时发布放进同一个营销工作台。基于产品信息和真实素材生成视频、图片及社交文案，可以直接与 AI CMO 协作，也可以接入自己的 Agent。

[MCP 服务](https://github.com/Qumge/autowhisper-mcp) · [Agent 技能](https://github.com/Qumge/autowhisper-skill)

## 37Soul — 给 Agent 一个持续成长的人格

[37Soul](https://37soul.com) 让 Agent 拥有一致的身份、与你的关系，以及逐渐积累的经历。把自己的 Soul 带到 Claude Code、Codex 等 Agent 中，也可以在网站上认识角色、与他们聊天。

[Agent 接入指南](https://37soul.com/for-agents) · [MCP 服务](https://github.com/Qumge/37soul-mcp) · [Agent 技能](https://github.com/Qumge/37soul-skill)

## Qumge — Agent 的能力市场

[Qumge](https://qumge.com) 让 Agent 按任务发现和调用 Capability，在明确的接口约定和价格下拿到执行结果。开发者可以发布能力并按调用获得收入；同一个预付余额也能通过兼容 API 使用模型。

[MCP 服务](https://github.com/Qumge/qumge-mcp) · [Agent 技能](https://github.com/Qumge/qumge-skill)

## Tali — 把学习资料变成每天的进步

[Tali](https://tali.run) 将学习资料整理成笔记、练习题和复习内容。设定考试日期，每天练习，通过间隔复习回顾薄弱知识点，以实际答题表现衡量进度。

## SpeakPen — 说下一个想法，让它继续生长

[SpeakPen](https://speakpen.app) 用手机或 Apple Watch 捕捉口述想法，整理成带转录和摘要的笔记。回顾值得保留的片段，结合 AI 和自己的知识库继续思考，也能把已有笔记带进 Agent 和 Obsidian 工作流。

[iOS App](https://apps.apple.com/app/id6743360755) · [MCP 服务](https://github.com/Qumge/speakpen-mcp) · [Agent 技能](https://github.com/Qumge/speakpen-skill) · [Obsidian 插件](https://github.com/xnjiang/speakpen-obsidian)
